## Overview

Altria is a renowned consumer products company with a portfolio of over 12 prestigious brands. The brand equity web application runs on the DNG platform, powered by **Adobe Experience Manager (AEM)**, with an ES6 JavaScript front end and Sass theming. It follows responsive web design principles, adheres strictly to web accessibility guidelines, and is backed by front-end unit testing and agile delivery practices.

## Role: UI Lead (Senior Lead)

Served as UI Lead across multiple tracks of the AEM implementation, contributing product and technical expertise and sharing knowledge across teams and the wider organisation.

## Responsibilities

- Led UI engineering efforts and managed development teams
- Oversaw end-to-end UI delivery across multiple tracks
- Owned code management and peer code reviews
- Ensured adherence to engineering best practices, accessibility, and test coverage
