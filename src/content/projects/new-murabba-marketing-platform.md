## Overview

A scalable web application using Next.js (ISR, Middleware, and API Routes) behind Cloudflare CDN with Redis-based caching, integrated with Sitecore backend services to enable personalised content delivery, business branding, and lead generation. Analytics and user behaviour tracking support audience insights, engagement measurement, and data-driven decision-making.
